Connect Slide Studio

Make slides from ChatGPT on any device

Connect once, then create presentations from your phone or the web—no desktop configuration required.

Connect Slide Studio in ChatGPT

How it works on iPhone and web

  1. Tap Connect Slide Studio above and connect the private plugin in ChatGPT (you may need to sign in or approve it).
  2. In any ChatGPT conversation, use the connected Slide Studio plugin and ask for a slide deck.
  3. Open the import link it returns on your phone or web browser, then approve importing your slides.
  4. Switch between Slides, Edit and Design, and tap Present when ready.

Plugin installation and availability depend on your ChatGPT account. This website cannot connect the plugin on your behalf.

Other MCP clients · manual setup

Add this server using the Streamable HTTP transport if your AI client supports custom MCP servers.

{
  "mcpServers": {
    "slide-studio": {
      "type": "streamable-http",
      "url": "https://slyz.vercel.app/api/mcp"
    }
  }
}

Your browser stores your slides locally. The MCP is stateless and can't read unshared local edits. Import links include slide text: avoid confidential information or patient data.

Already have slides at the original website address? Export the Slyz ZIP project there and import it here (older JSON files also work). Browser storage is isolated by domain.
